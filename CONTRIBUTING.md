# Contributing

1. Open an issue before substantial changes.
2. Keep app and `Templates/Project/` behavior in sync.
3. Run the relevant build, tests, parity check, and scaffold matrix.
4. Explain user-visible behavior changes in the pull request.
5. Do not include secrets, generated release artifacts, or unrelated cleanup.

See `AGENTS.md` and `docs/WORKFLOW.md` for repository conventions and
verification requirements.
