### WB-02 — Control evaluations, spike-first (Expander / LandingPages / Win2D)

- **Goal:** adopt only what beats the current answer on measured grounds; decline the rest on record.
- **Files:** spike scaffolds (temp, never committed) + evaluation notes (DECISIONS entries at commit time); adopted controls land in `Pages/` + `Controls/` (+ template mirror, same commit) — integration itself is WB-04.
- **Method (evaluate each, spike-first, house rule):**
  1. **`Expander`:** spike Settings/About grouping with `Expander` vs current stacked `SettingsCard`s. Measure: package delta (must be zero-dep — Toolkit already in graph), publish-weight delta (must be neutral), a11y delta (`A11yAuditTests` green unweakened + heading structure at least as good), visual delta (before/after shots for `controls.png`). Adopt iff all four hold; else keep stacked cards + document why.
  2. **`LandingPages`:** spike Home/About hero with Toolkit LandingPages vs current hero cards. Same four gates. Note the a11y bar is higher here (hero carries the page title + version pill + quick actions — headings + live regions must survive intact).
  3. **`Win2D`:** spike splash-art or icon-pipeline sample **outside** the default scaffold. Gate: native-dependency weight + guide-only shape. Likely outcome guide-only or declined — either is a complete result with a DECISIONS reason. Win2D never enters the default dependency graph without a weight verdict + matrix proof.
  4. **Already-adopted (`SettingsCard`, `Segmented`, `PipsPager`):** no re-spike. They are challenged only if a WB-02 candidate proposes replacing one — then the same four gates apply to the replacement.
- **Constraints:** zero new default dependencies without a DECISIONS reason + weight proof; no control adoption that weakens `A11yAuditTests` (strengthen-or-hold — v0.7.0 contract is a floor, not a ceiling); no fork of `MainWindow`/services for any control; hand-rolled controls (`WrapPanel`, `LocExtension`, toast/dialog surfaces) are replaced only by a measured beating, never by novelty.
- **Acceptance:** per-candidate verdict (adopt / guide-only / decline) with measured evidence (weight delta, test verdict, shots); adopted set named for WB-04; declined set carries DECISIONS entries with the measured reason (weight/dep/a11y/SDK-break).
