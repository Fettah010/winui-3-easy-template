# Phase C ready-to-publish kit

These drafts are prepared for the repository owner to review and publish.
They are intentionally not submitted automatically: community posts need
first-person context, disclosure, and moderation-specific formatting.

| File | Use |
| --- | --- |
| `awesome-winui-pr.md` | Adapt for an awesome-list pull request |
| `reddit-launch.md` | Adapt for r/WindowsAppSDK or r/dotnet |
| `articles.md` | Outlines for dev.to and Hashnode articles |
| `stack-overflow.md` | Disclosure-safe answer pattern |
| `screencast.md` | Five-minute demo script and transcript |
| `marketplace.md` | VS Marketplace investigation and decision |

Before publishing, replace bracketed placeholders, verify current package and
release versions, and link only to the canonical repository:
<https://github.com/Fettah010/winui-3-easy-template>.
